# v0.2.0-alpha.3 - Premium Tracker Baseline

## Purpose

This release records the stable internal-alpha baseline of Sadhana OS before
proactive coaching and life-integration product development begins.

It is a verified rollback and comparison point. It is not a declaration that
the application is ready for production customers.

## Included Baseline

- Premium responsive experiences for Today, onboarding, Journal, Dashboard,
  History, Settings, navigation, loading, empty, and error states.
- Email/password authentication, Google OAuth wiring, and secondary magic-link
  support with resend protection.
- Supabase cloud persistence, user-owned data isolation, Row Level Security,
  durable mutation replay, conflict detection, and cloud-sync status.
- Local-to-cloud migration safeguards, starter-data controls, cloud-aware
  export/import, and user-scoped local caching.
- Privacy controls, account deletion request UX, PWA installation foundation,
  observability abstraction, and environment status communication.
- Automated lint, typecheck, unit/integration, build, and Playwright E2E gates.
- Live development-cloud recovery, 38-check RLS validation, fresh-user
  validation, cross-user browser isolation, and persistence verification.

## Release Boundary

The following remain required before a public paid launch:

- A separate, fully validated staging Supabase project and deployed staging URL.
- A separate production Supabase project and production deployment.
- Production SMTP, branded authentication email, OAuth domain, and redirect
  configuration.
- Production monitoring vendor integration and privacy-safe analytics.
- Published privacy policy, terms, support contact, retention policy, and
  operational account-deletion validation.
- Backup/restore exercises, production smoke testing, pricing, billing, and
  controlled beta validation.
