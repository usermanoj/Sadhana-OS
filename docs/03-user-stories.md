# 03 — User Stories

Stories follow the format: **As a [persona], I want [action] so that [benefit].**

## Daily Tracking

| ID | Story | Priority |
|----|-------|----------|
| US-01 | As a practitioner, I want to see today's tracker with all my categories and sub-components so that I can log my daily practice. | P0 |
| US-02 | As a practitioner, I want to toggle each sub-component as done/not-done so that I can record what I completed. | P0 |
| US-03 | As a practitioner, I want to see my per-category and overall score update in real time so that I get instant feedback. | P0 |
| US-04 | As a practitioner, I want to navigate to a past date and edit entries so that I can back-fill missed days. | P1 |

## Category Management

| ID | Story | Priority |
|----|-------|----------|
| US-05 | As a practitioner, I want to add a new category so that I can track dimensions not included by default. | P1 |
| US-06 | As a practitioner, I want to edit a category's name, icon, and color so that I can personalise my tracker. | P1 |
| US-07 | As a practitioner, I want to archive a category so that it hides from daily tracking without losing history. | P1 |
| US-08 | As a practitioner, I want to restore an archived category so that I can resume tracking it. | P1 |
| US-09 | As a practitioner, I want to add, edit, reorder, and archive sub-components within a category. | P1 |

## Analytics

| ID | Story | Priority |
|----|-------|----------|
| US-10 | As a practitioner, I want to see a line chart of my overall score over 7/30/90 days so that I can observe trends. | P1 |
| US-11 | As a practitioner, I want to filter the chart by a specific category so that I can focus on one area. | P2 |
| US-12 | As a practitioner, I want to see my current streak count so that I stay motivated. | P2 |

## Journal

| ID | Story | Priority |
|----|-------|----------|
| US-13 | As a practitioner, I want to write a free-text journal entry for today so that I can reflect on my practice. | P1 |
| US-14 | As a practitioner, I want to view and edit past journal entries so that I can refine my reflections. | P2 |

## History

| ID | Story | Priority |
|----|-------|----------|
| US-15 | As a practitioner, I want to see a calendar view with color-coded days so that I can spot patterns at a glance. | P1 |
| US-16 | As a practitioner, I want to click a date on the calendar to load that day's data. | P1 |

## Audit Log

| ID | Story | Priority |
|----|-------|----------|
| US-17 | As a practitioner, I want every config change to be automatically logged so that I have a complete audit trail. | P0 |
| US-18 | As a practitioner, I want to view the audit log in chronological order and expand entries for details. | P1 |

## Export / Import

| ID | Story | Priority |
|----|-------|----------|
| US-19 | As a practitioner, I want to export all my data as JSON so that I can back it up. | P1 |
| US-20 | As a practitioner, I want to import a JSON backup so that I can restore or migrate data. | P1 |
| US-21 | As a practitioner, I want to export daily entries as CSV so that I can analyse data in a spreadsheet. | P2 |

## Mobile Experience

| ID | Story | Priority |
|----|-------|----------|
| US-22 | As a mobile user, I want the UI to be fully usable on a 360 px-wide screen with large touch targets. | P0 |
| US-23 | As a mobile user, I want smooth page transitions and no layout jank. | P1 |
